- For every inbound lead, we want to capture and persist:
  - service address
  - service(s) requested
  - rough timeframe for when they want it done
  - rough square footage when available
- Best operational flow for now:
  1. collect/complete required intake
  2. save it to CRM lead record + timeline/activity
  3. post it to Discord `#leads`
  4. human reviews and issues quote
- Decision: do **not** let AI fully auto-quote or fully close yet.
- AI should help qualify, organize context, and tee up quote-ready leads.

### Zak's exact nurture funnel to train on
- Opening message style:
  - casual, friendly, short, real-person texting tone
  - use agent name like Robin or Scout
- Core sequence:
  1. "Hey [Name], this is [Agent] with Wolf Pack Wash ... Has it been more or less than a year since it was last done?"
  2. regardless of answer, ask for exact service address so we can get exact price
  3. once address is received, quote using route-based phrasing:
     - "I have a route going out to [city] next week / in the next week or two..."
     - then give the house-wash quote and mention inclusions: trim, siding, windows/screens, soffit/eaves
  4. if they ask about add-ons, usually quote separately or bundle case-by-case
  5. hand off to human when they are ready to book / need exact handling
- Important: AI responses must have a global on/off toggle.
