## Facebook Lead Ads ↔ HH CRM integration (built today)
Two-way integration fully implemented by HH backend Replit agent:

### Inbound (Facebook → HH Supabase)
- Route: `GET /api/facebook/webhook` (Meta verification challenge)
- Route: `POST /api/facebook/webhook` (receives lead events)
- On receipt: fetches full lead from Graph API, deduplicates on meta_lead_id → phone → email, saves to CRM
- New Supabase table: `hh_fb_lead_details` — stores FB attribution per lead (campaign/adset/ad IDs + names, fbclid, raw payload, CAPI sync status)
- New Supabase table: `hh_integration_logs` — full audit trail for inbound and outbound events

### Outbound (HH CRM → Meta Conversions API)
- Service: `services/meta-capi.ts`
- Auto-triggered on every lead status change in the CRM
- PII hashed with SHA256 before sending (email, phone, name, city, state, zip)
- Status → Meta event mapping:
  - new → `Lead`
  - contacted → `Contacted`
  - quoted → `QualifiedLead`
  - scheduled → `AppointmentScheduled`
  - sold → `ConvertedLead`
- Dataset ID: `738171941965940`
- API endpoint: `https://graph.facebook.com/v25.0/738171941965940/events`
