### Real bugs caught and fixed during the typecheck pass

1. `/api/activity/webhooks/resend` had `return res.sendStatus(200)` BEFORE `handleResendWebhook(event)` ran — webhook events were silently dropped.
2. `/api/scores/batch` had `setImmediate(...)` AFTER `return res.json(...)` — background batch scoring never queued.
3. `/api/nurture/inbound` had `return res.send(twiml)` blocking `handleInboundSms` from running — inbound SMS replies were dropped.
4. `lead-scorer.ts` referenced `lead.notes` but schema renamed it to `conversationNotes`.
5. `hh_review_requests` schema in `sms.ts` was missing `twilioSid`. Added (+ notNull on customerName/customerPhone/scheduledAt/jobId).
6. Multiple `db.execute(text, params)` calls used pg pool style — Drizzle's `db.execute` only takes `sql\`\`` tagged template. Converted in nurture, scores, sms, lead-scorer.
7. JWT payload: code accessed `authUser.id`, real field name is `userId`.
